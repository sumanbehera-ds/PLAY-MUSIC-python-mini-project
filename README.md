# 🎵 PLAY-MUSIC Python Mini Project

A simple and user-friendly desktop **Music Player** built using **Python, Tkinter, and Pygame**.

This application allows users to **select, play, and stop MP3 files** through a minimal graphical interface.

<br>

**Author:** Suman Behera

---

## 🎵 Music Player (Python + Tkinter + Pygame)

A simple and user-friendly desktop music player built using **Python, Tkinter, and Pygame**.

This application allows users to:

- 🎶 Play MP3 music files  
- ⏹️ Stop currently playing music  
- 📂 Select music files from your system  
- ⚡ Use a lightweight and simple GUI  

---

## 🚀 Features

- 🎶 Play MP3 music files  
- ⏹️ Stop currently playing music  
- 📂 Select music files from your system  
- ⚡ Lightweight and easy-to-use GUI  
- 🖥️ Built with Tkinter for simplicity  

---

## 🛠️ Tech Stack

- Python  
- Tkinter (GUI)  
- Pygame (Audio Handling)  

---

## 📷 Sample Interface

```bash
[ Play ]
[ Stop ]
[ Select Music File ]
```
